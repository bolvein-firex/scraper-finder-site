Scraper Finder
v1.0.0

Find the right data app for any website.

Browse a live catalog of web data tools, auto-fill inputs, run the app on your Apify account, and export clean CSV or JSON.

Scraper Finder is a Chrome extension. It does not run a server and does not store org tokens.

  • Browse the public catalog without an account.
  • Connect your own Apify account to run data apps.
  • Save presets, schedule runs, and export results.
  • No analytics, advertising, or tracking.
