Privacy Policy

Last updated: October 31, 2026

Scraper Finder is a Chrome extension that helps you discover and run web data apps using your own Apify account.

What is stored

The extension stores the following locally in your browser:

  • Your Apify API token, if you connect an account.
  • Your display preferences and catalog settings.
  • The active tab URL, used to suggest data apps for the current site.
  • Inputs, presets, run metadata, and result data you create.
  • A local cache of the public data app catalog.

What is sent

  • To Apify: your token and run inputs are sent to api.apify.com when you validate your account, start a run, poll a run, fetch results, or create a schedule. Apify processes that data under its own privacy policy.
  • To GitHub Pages: the extension fetches the public catalog JSON from bolvein-firex.github.io. No token or personal data is included.
  • No analytics, advertising, tracking, or third-party servers. The extension does not sell or share data.

Permissions

  • storage / unlimitedStorage: save settings, presets, cached catalog, and run history locally.
  • tabs / activeTab: read the active tab URL so the extension can suggest relevant data apps.
  • sidePanel: show the extension in Chrome's side panel.
  • contextMenus: add "Find data apps for this page."
  • notifications: notify you when a run finishes while the extension is in the background.
  • Host permissions: call api.apify.com for public actor details, schemas, and user-authorized runs; read the public catalog from bolvein-firex.github.io.

Retention and deletion

  • Disconnect your Apify account to remove the token from local storage.
  • Use Settings → Clear cache to remove the catalog cache.
  • Use Recent runs → Clear history to remove local run metadata.
  • Delete presets individually from Saved presets.
  • Uninstalling the extension removes its local data.

Security

The Apify token is stored in chrome.storage.local and is sent only to api.apify.com. No org token is embedded in the extension. Do not install modified copies from untrusted sources.

Third-party services

  • Apify: https://apify.com/privacy-policy

Changes

If this policy changes, the updated version will be published with the extension.

Scraper Finder is an independent tool. Not affiliated with the websites it reads.
